# garden

A personal site. Generated by a C program. Some of it is alive because it's C compiled to wasm.

The absence is the point.

    blocks/*        the content. plaintext. one file per block. this is the database.
    src/garden.c    the generator. reads blocks/, writes site/.
    src/guestbook.c the one dynamic thing. a CGI. appends to a text file.
    src/wasm/*.c    ambient pieces. compiled freestanding, no libc, no emscripten.
    site/           generated output + hand-written CSS. this is what gets rsync'd.

## The model: everything is a block

There is no separate concept of a "post", a "quote", a "song", or a "page". There is one kind of
thing — a **block** — and edges between blocks. A collection is a block. A blog is a query.

One file per block, in `blocks/`. The filename stem is the ID; the extension is the type.

    blocks/
      rot-as-design.note
      nothing-lasts.quote
      stalker-water.clip
      spiegel-im-spiegel.audio
      merveilles.link
      maths.collection

### Format

A header, a `---` on its own line, then the body.

    title  Rot as a design principle
    date   2026-07-29
    tags   rot decay maths
    stage  seedling
    skin   austere
    contra nothing-lasts
    ---
    Body text. Links to other blocks look like [[nothing-lasts]].
    Embedding another block inline looks like ![[nothing-lasts]].

    > marginalia go in blockquote-with-a-caret, rendered as <aside>

All header fields are optional except `title`. Unknown fields are preserved and ignored — add your
own, the generator won't care.

### Types

`note` `quote` `link` `collection` `poem` `image` `audio` `video` `html`

A `.html` block is a page you wrote by hand: the body is emitted **exactly** as written, no
parsing and no escaping. Same trust model as the `:::` fence, applied to the whole file.

The type is the file extension. `image`/`audio`/`video` blocks read `src`, `poster`, `alt`, and
`caption` from the header and emit their element before the body. Nothing autoplays, nothing
preloads — a clip waits to be asked for. `src` must be site-relative: no scheme, no `//host`, no
`..`.

### The five mechanisms

**`[[id]]` — a link.** Creates a directed edge. Every page prints `incoming:` at the bottom,
computed by reversing every edge in the graph. You navigate by wandering, not by hierarchy.

**`![[id]]` — transclusion.** The whole design rests on this. One quote block renders *inline*
inside an essay, *stands alone* at its own URL, and *appears* in three collections — one file,
three lives. Without transclusion this is just a wiki with extra steps.

**`.collection` — a block whose body is a list of `[[ids]]`.** Because collections are blocks, a
collection can contain a collection. Nesting for free, zero extra code.

**`~~~` — verse.** Everything between two `~~~` lines is preserved to the column. This is what
concrete poetry needs and what markdown cannot give you. `~~~name` adds a class.

**`{cls|text}` — an inline span.** `<span class="cls">text</span>`. Spans nest. Any class defined
in any skin is instantly available per word — the markup never needs to know the class exists.
Also `==mark==`, `**strong**`, `*em*`, `` `code` ``.

**`:::` — raw HTML, verbatim.** No escaping, no parsing, no opinion. The freedom knob: when CSS
can't do it, write the markup yourself. Safe because these are your own files on your own disk —
guestbook entries will never go through loam.

### Per-page freedom

Any block header may set these. A page can ignore all of them or use every one and look like
nothing else on the site.

| field | does |
|---|---|
| `skin` | loads `/skins/<name>.css` — a whole stylesheet, for anything a header line can't hold |
| `font` | body `font-family` |
| `fontsrc` | a woff2 url; emits `@font-face`, then set `font  pageface` |
| `size` | body font-size |
| `measure` | line length |
| `ink` / `paper` | text and background colour |
| `css` | one line of CSS, injected verbatim |
| `class` | extra classes on `<body>` |
| `leading` `tracking` `weight` `align` | line-height, letter-spacing, weight, text-align |
| `columns` | multi-column article |
| `rule` `step` | rule colour, vertical rhythm |
| `scroll` | `reverse` (wheel inverted) or `horizontal` (columns, pushed sideways) |
| `js` | loads `/js/<name>.js` |
| `wasm` | loads `/wasm/<name>.wasm` and the glue that drives it |
| `bg` | runs a character field behind the page. a program name, or `none` |
| `bgchars` | the ramp that field is drawn with, dark to light |
| `bgopts` | one line of `k=v` dials for it |
| `draft` | `yes` removes the block completely — 404 on its own URL, gone from every index, tag, backlink and transclusion. The file stays on disk. |
| `hidden` | `yes` is the softer version — reachable by URL, absent from all listings. |

`skin` is validated as an id and `fontsrc` as a site-relative path — a traversal in either is
dropped, not emitted.

### Fonts

Drop a `.woff2` into `site/fonts/`. That's the whole registration step — `/fonts.css` is generated
per request from the folder, giving you `font  <name>` as a header field and `{f-<name>|word}` as
inline markup. Subset first:

    pyftsubset face.ttf --output-file=site/fonts/name.woff2 --flavor=woff2 \
      --unicodes="U+0020-007E,U+00A0-00FF" --layout-features='kern,liga' --no-hinting

The six here are 12–20KB each; an unsubset TTF is often 700KB.

### WASM

    make wasm

Freestanding `wasm32` — no emscripten, no libc, nothing but `clang` and `wasm-ld`. Put a `.c` in
`src/wasm/`, add a handler to `site/js/wasm.js`, set `wasm  <name>` in a block header.

Three modules ship, all under 2KB:

| module | what | keys |
|---|---|---|
| `ascii` | the Mandelbrot set rendered as text | space runs the zoom, r resets |
| `life` | Conway, wrapping, in text | space, n steps, r reseeds |
| `crossword` | a 5×5 mini — C owns the grid, the numbering and the answers | arrows, tab, ? checks, ! reveals |

`-nostdlib` means no `memset`, but clang still *emits* calls to it for zero-init, so each module
supplies its own four-line version or the link fails. No `sin`/`pow` either — that is why the
graphics here are escape-time and cellular rather than trigonometric.

The JS never sees a crossword answer: it draws a table and forwards keystrokes. Everything else
crosses as bytes — an exported `char*` is an offset into the module's linear memory, which on the
JS side is just an `ArrayBuffer`.

Every module pauses off-screen via `IntersectionObserver` and does not animate at all under
`prefers-reduced-motion`.

### The character field

    site/js/textmode.js   the engine
    site/js/programs.js   fourteen things to run on it
    site/js/backdrop.js   the layer behind the page, and the floating links

A page can wear a grid of characters behind it. The idea and several of the programs come
from [ertdfgcvb](https://github.com/ertdfgcvb/play.core); the engine is a rewrite, because
play.core keeps one object per cell and spreads a fresh copy of every cell every frame. Here
a cell is two integers in two typed arrays and a frame allocates nothing.

    bg      warp
    bgchars  .:-=+*#%@
    bgopts  fps=24 scale=1.4 fade=.3 drift=body seed=x word=gdn rd=coral

Three fields rather than twelve, because a block only gets 32 (`LOAM_MAX_FIELDS`) and they
are shared with `title`, `date`, `tags` and the rest. The dials go on one `bgopts` line the
way `css` holds one line of CSS. Everything reaches the browser as `data-*` on `<body>`,
escaped once — never as CSS, because `csssafe` only drops angle brackets and a ramp is
allowed to *contain* angle brackets.

**Off by default.** Set `SITE.bg` in `lua/render.lua` for a site-wide field. The three files
are 64KB together, and the home page has 100KB to spend on everything — so turn it on for
the pages that are about it, not for the whole garden. `bg  none` in a header opts one page
out.

Precedence is `block header < localStorage < query string`. A reader's stored preference
beats the page's, which is the point; `/?bg=plasma&bgopts=speed%3D2` is a link to a specific
field rather than to a page that happens to have one.

**Two layers, and that is the performance story.** A grid with no styles and no links is
written as one string and one `textContent` assignment for the whole screen. One coloured
link in it would force every row to be built out of `<span>`s instead — so the field is one
`<pre>` and the floating links are another, where nearly every row is empty, unchanged and
skipped. Rows are compared as integers and only changed rows are written.

The floating links are not new markup: they are the page's own nav and backlinks, harvested
from the DOM and composited into the grid, so both layers are `aria-hidden` and `lynx` sees
no duplicate list. They arrive by split-flap, counting up through the charset.

Everything pauses off-screen and in a hidden tab, and under `prefers-reduced-motion` the
field is composed exactly once and left alone. At 160×50, steady state, every program costs
under 3ms a frame except the raymarcher, which is meant to be looked at rather than sat
behind text.

`/b/ascii` runs all of them at once, `/b/background` is the control panel, `/b/textmode`
is what the deobfuscation turned up.

### Mounts

`site/mnt/<name>` is a symlink to a folder elsewhere on disk. Those are the **only** paths allowed
to leave `site/`, and the only ones that get a directory listing.

    ln -s ~/repos/buks site/mnt/buks

Files stream from disk in 64KB chunks — a 50MB PDF never lands in memory. Containment is a textual
`..` reject plus a `realpath()` containment check, which also catches a symlink *inside* the tree
pointing at `/etc`. Dotfiles are never listed or served. Mounts are gitignored: a symlink to an
absolute path is meaningless in a clone and leaks your directory layout.

**A mount publishes everything under it, recursively, to anyone who can reach the server.** Right
now that's localhost only. Check the folder before this reaches a VPS.

### Very large pages

Bodies up to 64MB. Responses are written with a `write_all` loop — a single `write()` silently
truncates anything past the socket buffer. Blocks past 3KB with 3+ headings get an automatic
contents block; every `## ` heading gets a stable anchor.

Measured: a 7.9MB block renders to 8.4MB of HTML in 251ms, RSS peaking at 37MB and returning to
4MB when the arena resets.

### Routes

    /                  home, grouped by type
    /b/<id>            a block
    /tags              every tag with a count
    /tag/<tag>         blocks carrying that tag
    /contradictions    declared disagreements, paired side by side
    /mnt               mounted folders
    /mnt/<name>/...    browse and stream from a mount
    /fonts.css         generated from site/fonts/

### Fields that earn their keep

| field | does |
|---|---|
| `contra` | IDs this block disagrees with. Generates `/contradictions`, pairing them side by side. Edge is symmetric — declare it on either side. |
| `stage`  | `seedling` \| `budding` \| `evergreen` \| `rotting`. Shown as a mark. With `date`, pages visibly age. |
| `skin`   | which stylesheet loads on top of `base.css`. A serious essay is austere, a rant is chaotic. |

**Never edit the past.** If you stop believing something, append a dated `> I no longer believe
this` rather than rewriting. The rot is the record.

## Rules the build enforces

- Home page **under 100KB** total, including wasm. `make check` fails the build otherwise.
- No media auto-loads. Poster frame, `preload="none"`, click to play. Ever.
- Every wasm piece pauses off-screen and renders one static frame under `prefers-reduced-motion`.
- Every page must be readable in `lynx` and with CSS disabled.
- Zero requests to any host but this one.

## Run

    make               # build ./garden  (needs luajit or lua5.1 headers)
    ./garden           # serve on localhost:8000
    ./garden 9000      # ...or another port
    ./garden -r <id>   # render one block to stdout. no socket. good for debugging.
    make check         # weight budget. fails loud.

Bound to `127.0.0.1` only. It never lists a directory: `/` is a real home page, unknown
paths get a 404, and the only files served off disk are static assets under `site/`.

`lua/render.lua` is re-read on every request, so template edits show on refresh with no
restart. A broken template gives you a 500 and a stack trace in the terminal instead of
taking the server down.

## Who does what

**C** — sockets, files, the loam parser, escaping. `src/loam.c` owns `buf_esc`, and every
byte of block text goes through it. There is exactly one escaping path on purpose, and `:::`
is the single deliberate exception.

**Memory** — one arena per request (`src/arena.c`). Every allocation a request makes comes
out of it, and `arena_reset` releases the whole thing in one call after the response is
written. There is no `free()` in `garden.c`. Nothing can leak, double-free, or be used after
free, because nothing is freed individually. RSS stays flat at ~3MB under load.

**Lua** — page shapes, the nav, the footer. `lua/render.lua`. This is the file you'll edit
twenty times a day, which is why it isn't C.

C only pushes header fields that exist, so optional fields arrive in Lua as `nil`. Use the
`f(t, k)` helper, never `t.k` directly.
